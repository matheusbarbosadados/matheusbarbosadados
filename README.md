## 📚 Como comecei na área de Dados

Minha base profissional foi construída em **rotinas administrativas, faturamento e relacionamento com clientes**. A necessidade de validar bases operacionais e automatizar controles de cadastros me fez mergulhar no Excel Avançado.

No início, não imaginava que a criação de planilhas dinâmicas pudesse se tornar uma nova possibilidade profissional. Conforme as funções lógicas começaram a fazer sentido, percebi que havia encontrado uma área que realmente despertava meu interesse. 

A partir daí, iniciei a graduação em Banco de Dados e ampliei meus estudos em Python, SQL e Power BI através de formações oferecidas por instituições como **Udemy, Fundação Bradesco, Santander e ENAP**.

O que começou como uma necessidade do trabalho acabou se transformando em uma **rotina de estudos focada em Inteligência de Negócios**.
